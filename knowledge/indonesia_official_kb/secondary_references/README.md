## If you add something here

This folder is for material that is *useful but not authoritative* — a consultant's explainer that helps locate a regulation, a firm's summary table used as a cross-check.

Rules:

1. It may **never** be a `source_id` on a rule candidate.
2. It may **never** justify a rate, base or effective date.
3. Mark every file `NON-AUTHORITATIVE` at the top, with the date and why it was kept.
4. If it points at a regulation, go and get the regulation — then cite that instead.
