# CFO AI — финальный дизайн v2 (3 октября 2026)

## Что в папке

| Что | Где |
|---|---|
| Кликабельный прототип: все экраны в одном приложении, desktop и телефон | `prototype/CFO-AI-prototype.html`. Открой в браузере. |
| Скриншоты всех экранов | `screens/desktop` (30) и `screens/phone` (9) |
| Исходники экранов для разработчика | `designs/*.dc.html` |
| Спецификация: экраны → маршруты → файлы в коде, правила, что не нарисовано | `specs/DESIGN_SPEC.md` |
| Как считаются прибыль, деньги и прогноз | `specs/PERFORMANCE_METRICS.md`, `specs/model/` |
| Промпт для Claude Code | `PROMPT_FOR_CLAUDE_CODE.md` |

## Как передать в разработку

1. Положи всю эту папку в репозиторий `helm-finance-web` по пути `_specs/design-v2/`.
   - В итоге получится `_specs/design-v2/PROMPT_FOR_CLAUDE_CODE.md`, `_specs/design-v2/specs/…` и так далее.
   - Промпт ссылается на эти пути.
2. Открой новую сессию Claude Code на репозитории.
3. Вставь в неё текст из `PROMPT_FOR_CLAUDE_CODE.md`.
4. Claude сначала напишет план (batch 0), потом пойдёт этапами 1–7.
   - Каждый этап — отдельная ветка и PR. Сам Claude ничего не сливает: проверяет Codex, сливаешь ты.
   - Всё новое спрятано за флагом `VITE_DESIGN_V2`, по умолчанию он выключен. Пока ты его не включишь, продакшен не меняется.
   - Миграции, авторизацию, платежи и env он не трогает. Вместо этого присылает предложения в `_specs/design-v2/PROPOSALS.md` тебе на одобрение.

## Важно

- Все цифры на экранах демонстрационные (выдуманная компания «Nusantara Facilities»). В приложении будут твои реальные данные.
- Не нарисованы:
  - пустые состояния и экраны загрузки;
  - окно Add на компьютере;
  - биллинг;
